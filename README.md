# منصة إدارة المخالفات – هيئة الإعلام والاتصالات العراقية

نظام مؤسسي لأتمتة دورة المخالفة الإدارية كاملة: التسجيل، ورفع المحضر، والمصادقات الفنية والقانونية، وإصدار الإنذار وتبليغه، واحتساب المدد، والاستجابات، والدعوى الجزائية، والحكم، والإغلاق الموثّق.

> **حالة المشروع:** يُنفَّذ على 8 أجزاء (انظر [PLAN.md](PLAN.md)). **الجزء الأول (التأسيس) مكتمل.** الأقسام التي لم تُنفَّذ بعد لا تظهر في القائمة، فلا توجد صفحات شكلية.

## التقنيات

| الطبقة | الاختيار |
|---|---|
| الواجهة والخادم | Next.js 15 (App Router، Server Actions) + React 19 + TypeScript |
| التصميم | Tailwind CSS 4، RTL من الجذر، خط IBM Plex Sans Arabic مضمَّن محلياً (يعمل دون إنترنت) |
| قاعدة البيانات | PostgreSQL 16 + Prisma 6 |
| المصادقة | جلسات في قاعدة البيانات + Argon2id + قفل الحساب وتحديد معدل المحاولات |
| التحقق | Zod |
| الاختبارات | Vitest (منطق الأعمال وقاعدة البيانات) + Playwright (الواجهة على الحاسوب والهاتف) |
| التشغيل | Docker / Docker Compose لخادم الهيئة، أو Netlify + Supabase |

## التشغيل محلياً

المتطلبات: Node.js 20.18 أو أحدث، وPostgreSQL 14 أو أحدث.

```bash
npm ci
cp .env.example .env          # عدّل DATABASE_URL وAPP_SECRET وCRON_SECRET
npm run db:migrate            # تطبيق الترحيلات
npm run db:seed               # الصلاحيات والأدوار والمحافظات والقوائم المرجعية (لا يُنشئ أي حساب)
npm run admin:create          # إنشاء أول مدير نظام تفاعلياً (كلمة المرور لا تُخزَّن في المستودع)
npm run dev                   # http://localhost:3000
```

أو باستخدام Docker:

```bash
cp .env.example .env   # أضف POSTGRES_PASSWORD وAPP_SECRET وCRON_SECRET
docker compose up -d --build
docker compose exec app npx tsx prisma/seed.ts
docker compose exec -it app npx tsx scripts/create-admin.ts
```

## إنشاء أول مدير نظام بأمان

يطلب الأمر `npm run admin:create` اسم المستخدم والاسم الكامل وكلمة المرور تفاعلياً، ويخفي كلمة المرور أثناء كتابتها. لا توجد حسابات افتراضية، ولا كلمات مرور معروفة.

**دور مدير النظام لا يملك أي صلاحية مصادقة رسمية.** بعد الدخول، أنشئ حسابات الموظفين وأسند إليهم أدوارهم من صفحة «إدارة المستخدمين والصلاحيات». يحصل كل موظف على كلمة مرور مؤقتة تُعرض مرة واحدة، ويُلزَم بتغييرها عند أول دخول.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` / `build` / `start` | التطوير، والبناء، والتشغيل |
| `npm run typecheck` / `lint` | فحص الأنواع وجودة الشيفرة |
| `npm test` | اختبارات Vitest (تُنشئ مخططاً مؤقتاً في قاعدة الاختبار وتحذفه بعد الانتهاء) |
| `npx playwright test` | اختبارات الواجهة (تتطلب خادماً قيد التشغيل) |
| `npm run db:migrate` | تطبيق الترحيلات (غير هدّام) |
| `npm run db:seed` | زرع البيانات الأساسية (آمن للتكرار، ولا يعيد كتابة تعديلات الإدارة) |
| `npm run admin:create` | إنشاء مدير نظام |
