# نظام إدارة العمل الإداري والتنظيمي

منصة عربية (RTL) تعمل على الحاسوب والموبايل لإدارة قاعدة بيانات الأشخاص، والطلبات الواردة، وتوزيع المهام بموافقة المكلفين، ومتابعة الإنجاز، والتقارير الإدارية، مع سجل تدقيق كامل.

> هذا التطبيق مستقل عن منصة إدارة المخالفات الموجودة في جذر المستودع: له قاعدة بيانات وحزم وإعدادات خاصة به.

## حالة التنفيذ

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | قاعدة البيانات الكاملة ومخطط العلاقات، تسجيل الدخول، الأدوار والصلاحيات، إدارة المستخدمين، سجل التدقيق المحمي، القوائم المرجعية والإعدادات | ✅ مكتملة ومختبرة |
| 2 | لوحة المتابعة (مؤشرات الأشخاص التفاعلية والتوزيعات)، إدارة الأشخاص: إضافة وتعديل وبحث وفلاتر وفرز، سجل التعديلات لكل سجل، استيراد Excel بمعاينة صف بصف، تصدير Excel، كشف الأسماء المتشابهة والدمج، الحذف الناعم والاستعادة | ✅ مكتملة ومختبرة |

| 3 | الطلبات وسجلها الزمني، المهام وموافقة المكلف، ومؤشراتها في لوحة المتابعة | ⏳ التالية |
| 4 | التقارير (PDF/Excel) والتنبيهات | — |
| 5 | اختبار الصلاحيات والحماية والاستيراد والتصدير، النسخ الاحتياطي والاستعادة | — |
| 6 | الاختبار على الحاسوب والموبايل وتجهيز النشر | — |

لا يظهر أي قسم في القائمة قبل تنفيذه فعلياً (`IMPLEMENTED_PHASE` في `src/lib/nav.ts`).

## التقنيات

| الطبقة | الاختيار |
|---|---|
| الواجهة والخادم | Next.js 15 (App Router، Server Actions) + React 19 + TypeScript |

| قاعدة البيانات | PostgreSQL 14+ مع Prisma 6 (مركزية، وليست تخزيناً في المتصفح) |

| الاختبارات | Vitest على قاعدة PostgreSQL حقيقية |

## التشغيل محلياً

المتطلبات: Node.js 22.9 أو أحدث، وPostgreSQL 14 أو أحدث.

```bash
cd admin-work
npm ci
cp .env.example .env          # عدّل DATABASE_URL وAPP_SECRET
npm run db:migrate            # تطبيق الترحيلات
npm run db:seed               # المحافظات والإعدادات الافتراضية (لا يُنشئ أي حساب)
npm run admin:create          # إنشاء أول مدير نظام تفاعلياً
npm run dev                   # http://localhost:3100
```

لا توجد حسابات افتراضية ولا تسجيل ذاتي. بعد دخول المدير، ينشئ حساب المنسق العام من صفحة «المستخدمون والصلاحيات» ويحدد صلاحياته التشغيلية. تظهر كلمة المرور المؤقتة مرة واحدة، ويُلزَم صاحبها بتغييرها عند أول دخول.

## الأدوار

| | مدير النظام | المنسق العام |
|---|---|---|
| الصلاحيات | جميعها دائماً | الصلاحيات التشغيلية التي يمنحها المدير فقط |
| إدارة الحسابات والصلاحيات | ✅ | ❌ (لا يُنشئ مديراً ولا يعدّل حسابه) |
| اعتماد إغلاق الطلبات والمهام، والحذف، والدمج | ✅ | ❌ |
| القوائم المرجعية والإعدادات وسجل التدقيق | ✅ | ❌ |

تُفرض الصلاحيات في الخادم داخل كل صفحة وإجراء. وحتى لو عُدّلت صلاحيات المنسق مباشرة في قاعدة البيانات، يُسقط النظام أي صلاحية إدارية منها.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` / `build` / `start` | التطوير، والبناء، والتشغيل (المنفذ 3100) |
| `npm run typecheck` / `lint` | فحص الأنواع وجودة الشيفرة |
| `npm test` | الاختبارات (تُنشئ مخططاً مؤقتاً في قاعدة الاختبار `TEST_DATABASE_URL` وتحذفه في النهاية) |

| `npm run admin:create` | إنشاء مدير نظام |

## قاعدة بيانات الأشخاص

- **حالة البيانات تُحتسب تلقائياً**: «مكتملة» عند تحديد المحافظة/المنطقة ومسؤول المتابعة، و«ناقصة» عند غياب أحدهما، و«بانتظار التحديث» إذا عُلِّم السجل بذلك. رقم الهاتف اختياري.
- **تحتاج إلى تحديث** (في اللوحة والفلتر): السجلات «بانتظار التحديث» أو التي لم تُعدَّل منذ عدد الأيام المحدد في الإعدادات (90 افتراضياً).
- **منع التكرار**: رقم الهاتف لا يتكرر مطلقاً. الاسم المطابق (بعد توحيد الهمزات والتاء المربوطة والتشكيل والمسافات) يُرفض إلا إذا أكد المستخدم أنه شخص مختلف، ويُحفظ هذا التأكيد. الأسماء المتشابهة تظهر أثناء الكتابة، وفي صفحة «مراجعة الأسماء المتشابهة».
- **الدمج** (للمدير): يُكمل الحقول الفارغة في السجل المُبقى عليه، وينقل إليه المهام والطلبات، ويحذف الآخر حذفاً ناعماً مع الإشارة إليه.
- **الاستيراد**: يُفحص الملف أولاً (الحقول، المحافظات، أسماء المستخدمين، التكرار داخل الملف ومع قاعدة البيانات)، ثم تُستورد الصفوف السليمة فقط بعد التأكيد. القالب متاح للتنزيل من صفحة الاستيراد.
- **التصدير**: يصدّر السجلات المطابقة للفلاتر الحالية، ويُسجَّل في سجل التدقيق.
