# الاختبار

## الاختبارات الآلية (`npm test`)

تعمل على PostgreSQL حقيقية: كل تشغيل ينشئ مخططاً مؤقتاً في قاعدة الاختبار (`TEST_DATABASE_URL`، ويجب أن يحتوي اسمها كلمة test)، ويطبق الترحيلات والبيانات الأساسية، ثم يحذف المخطط في النهاية.

| الملف | يغطي |
|---|---|
| `auth.test.ts` | الدخول، الرسالة الموحدة، قفل الحساب، الحساب المعطل، انتهاء الجلسة بالخمول وبالخروج، سياسة كلمة المرور، إنهاء الجلسات الأخرى، تسجيل الدخول في التدقيق |
| `rbac.test.ts` | ترشيح صلاحيات المنسق، إنشاء الحسابات، منع منح صلاحيات إدارية، منع المنسق من إدارة الحسابات، حماية آخر مدير، إعادة تعيين كلمة المرور |
| `audit.test.ts` | سلسلة التجزئة، رفض تعديل سجل التدقيق وحذفه وتفريغه، السجلات الزمنية الإلحاقية، القيود الفريدة، القوائم المرجعية والإعدادات |
| `people.test.ts` | توحيد الأسماء والهاتف، حالة البيانات، منع التكرار، الأسماء المتشابهة، الدمج، الحذف والاستعادة، البحث والفلاتر، السجلات القديمة، الاستيراد صفاً صفاً، التصدير |
| `requests-tasks.test.ts` | الترقيم المتزامن، سير حالات الطلب، التعذر والإغلاق، الطلبات المتأخرة، موافقة المكلف، تعديل الموعد، الاعتذار وإعادة الإسناد، مراحل الإنجاز، الإغلاق والإلغاء |
| `phase4.test.ts` | التنبيهات الفورية والدورية ومنع التكرار، الفترات الزمنية، التقارير الثمانية وتصديرها، تهريب HTML في التقارير |
| `security.test.ts` | مصفوفة الصلاحيات على طبقة الأعمال، الاستعلامات الخبيثة، صيغ Excel في التصدير، ملفات الاستيراد الخبيثة، حد محاولات الدخول لكل IP |

**النتيجة الحالية: 62 اختباراً ناجحاً.**

## فحوص الأمان عبر HTTP (`npm run test:security`)

تعمل على خادم قيد التشغيل وقاعدة اختبار، لأنها تُنشئ حساباً وسجلات:

```bash
E2E_BASE_URL=http://localhost:3100 E2E_ADMIN_USER=<المدير> E2E_ADMIN_PASS=<كلمة المرور> npm run test:security
```

تتضمن 72 فحصاً:
- كل صفحة وواجهة تنزيل دون جلسة، وبملف جلسة مزوّر.
- المهمة المجدولة دون السر أو بسر خاطئ.
- الترويسات الأمنية وخصائص ملف الجلسة.
- حقن نصوص برمجية في الأسماء والأوصاف وفحص عدم تنفيذها في 8 صفحات.
- رفض الإجراء الخادمي القادم من موقع خارجي.
- إعادة استخدام ملف الجلسة بعد الخروج.
- حساب «مطلع فقط» يُمنع من 15 صفحة و5 واجهات تنزيل ومن فتح طلب برابطه المباشر.
- قفل الحساب بعد 5 محاولات فاشلة.

**النتيجة الحالية: 72/72 ناجحة.**

## تمرين النسخ الاحتياطي والاستعادة

نُفّذ على قاعدة فيها بيانات من اختبارات المتصفح:

```bash
BACKUP_KEY=<المفتاح> npm run backup -- --out ./backups --keep 30
BACKUP_KEY=<المفتاح> npm run restore -- --manifest ./backups/aw-....manifest.json --target "postgresql://.../قاعدة_فارغة"
```

| الحالة | النتيجة |
|---|---|
| استعادة إلى قاعدة فارغة | نجحت: 16 جدولاً، وتطابقت أعداد الصفوف، وكل سجلات التدقيق سليمة |
| استعادة فوق قاعدة غير فارغة | رُفضت |
| مفتاح خاطئ | رُفضت برسالة واضحة |
| بعد الاستعادة | مشغّلات حماية سجل التدقيق والبحث التقريبي عن الأسماء تعمل |
| الاحتفاظ (`--keep 2`) | بقيت آخر نسختين فقط |
